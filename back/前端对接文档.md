# 前端对接文档（4号 · 可视化岗）

## 后端信息

| 项目 | 值 |
|---|---|
| 地址 | `http://127.0.0.1:5000` |
| 数据格式 | JSON |
| 编码 | UTF-8 |
| 鉴权方式 | `Authorization: Bearer <token>` |

---

## 一、认证接口

### 注册（三种角色）

```
POST /api/auth/register
Content-Type: application/json

管理员：{ "username":"admin01", "password":"admin123", "role":"admin" }
教师：  { "username":"teacher01", "password":"teach123", "role":"teacher", "course_id":"C101" }
学生：  { "username":"stu01", "password":"stu123", "role":"student", "student_id":"STU100000" }
```

### 登录

```
POST /api/auth/login
{ "username":"admin01", "password":"admin123" }

返回：{ "token":"eyJ...", "user":{ "user_id":1, "username":"admin01", "role":"admin", ... } }
```

> 拿到 token 后，后续所有请求头加：`Authorization: Bearer <token>`

### 当前用户信息

```
GET /api/auth/me
Authorization: Bearer <token>
```

## 二、大屏 & 数据总览页（ECharts 折线图/饼图/柱状图）

### 概览指标卡（4个数字）

```
GET /api/overview/metrics
Authorization: Bearer <token>

返回示例：
{
  "student_count": 100000,       ← 学员总数
  "course_count": 8,             ← 课程总数
  "high_risk_count": 3711,       ← 高风险学员数
  "avg_completion_rate": 49.03   ← 平均完成率(%)
}
```

### 周学习趋势（折线图）

```
GET /api/overview/weekly-trend?limit=24
Authorization: Bearer <token>

返回示例（数组）：
[
  { "week_label":"2023-W02", "learning_times":245, "learner_count":245,
    "total_study_time_hours":903.3, "avg_quiz_score":74.44 },
  ...
]
```
> ECharts x轴用 `week_label`，y轴可选 `learning_times` / `avg_quiz_score`

### 课程报名排行（柱状图）

```
GET /api/overview/course-enrollment
Authorization: Bearer <token>

返回示例：
[
  { "enrollment_rank":1, "course_id":"C101", "course_name":"Python Basics", "learner_count":16807 },
  ...
]
```

### 预警等级分布（饼图）

```
GET /api/overview/warning-distribution
Authorization: Bearer <token>

返回示例：
[
  { "warning_level":"低风险", "student_count":46599, "risk_ratio_pct":46.6 },
  { "warning_level":"中风险", "student_count":27618, "risk_ratio_pct":27.62 },
  { "warning_level":"安全",    "student_count":22072, "risk_ratio_pct":22.07 },
  { "warning_level":"高风险",  "student_count":3711,  "risk_ratio_pct":3.71 }
]
```
> 饼图用 `warning_level` 做名称，`student_count` 做数值

## 六、预警分析页

### 预警等级统计

```
GET /api/warnings/levels
Authorization: Bearer <token>

返回示例（见上面预警等级分布）
```

### 学生预警明细（表格 + 筛选）

```
GET /api/warnings/students?warning_level=高风险&course_id=C101&page=1&page_size=20
Authorization: Bearer <token>

返回示例：
{
  "total": 100000,
  "page": 1,
  "page_size": 20,
  "rows": [
    { "Student_ID":"STU100003", "Course_ID":"C105", "Course_Name":"UI/UX Design Fundamentals",
      "Education_Level":"Diploma",
      "warning_level":"中风险", "risk_sum":2, "Quiz_Score_Avg":"59.10",
      "Assignment_Submission_Rate":"0.00", "Progress_Percentage":"24.70",
      "Video_Completion_Rate":"63.30",
      "is_login_risk":1, "is_homework_risk":1,
      "is_progress_risk":0, "is_score_risk":0 },
    ...
  ]
}
```

> 筛选参数（可选）：`warning_level`（高风险/中风险/低风险/安全）、`course_id`、`student_id`、`education_level`、`page`、`page_size`
> 四维风险标记：`is_login_risk` / `is_homework_risk` / `is_progress_risk` / `is_score_risk`，值为 0/1

### 四维风险汇总

```
GET /api/warnings/risk-dimensions
Authorization: Bearer <token>

返回示例：
{
  "login_risk_count": 34156,
  "homework_risk_count": 33892,
  "progress_risk_count": 33104,
```

## 七、角色权限说明

| 角色 | 权限范围 |
|---|---|
| admin | 全部接口可用 |
| teacher | 总览/预警/资源/教师画像（仅自已课程） |
| student | 仅自己的学生画像详情 |
